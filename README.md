# CS 330 Comp Graphic and Visualization

## Final Project: 3D Desktop Workstation Scene

This repository contains my final project for CS 330 Comp Graphic and Visualization. For this project, I created a 3D desktop workstation scene using C++ and OpenGL. The scene includes a monitor, keyboard, desk surface, and desk lamp. The project demonstrates low-polygon modeling, textures, lighting, camera controls, and organized OpenGL code.

## Project Files

* `CS330_Final_Project.zip` contains the full 3D scene project files.
* `Design_Decisions.docx` explains the design choices, development process, navigation controls, lighting, textures, and custom functions used in the project.

## Reflection

### How do I approach designing software?

I approach designing software by first breaking the project into smaller parts. For this project, I looked at the desktop workstation scene and identified the main objects I needed to create, such as the monitor, keyboard, desk surface, and lamp. I then matched each object with basic shapes like boxes, cylinders, cones, and planes. This helped me keep the scene simple while still making it recognizable.

This project helped me improve my design skills by showing me how important object placement, scale, lighting, and textures are in a 3D scene. I learned that even small changes, such as changing the table size or moving a light source, can affect how the final scene looks. My design process involved testing one part at a time, reviewing the result, and then making adjustments. This same process can be applied to future work because breaking a project into smaller pieces makes it easier to manage and improve.

### How do I approach developing programs?

I approach developing programs through iteration. I usually start with a basic working version, then add features and improvements step by step. In this project, I started with simple objects and then added textures, lighting, and camera controls. I also made changes throughout the milestones based on what worked and what did not work visually.

One development strategy I used was testing changes frequently. For example, I adjusted the desk size, changed textures, removed the back wall, and added a desk lamp after seeing how the lighting behaved in the scene. Iteration was important because the first version did not always give the best result. My approach to coding evolved throughout the milestones because I became more comfortable organizing code into helper functions for transformations, textures, materials, and lighting.
